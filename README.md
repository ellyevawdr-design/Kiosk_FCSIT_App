# Network Clan Kiosk FCSIT App

##  How to Start
1. **Clone the repo:** `git clone https://github.com/ellyevawdr-design/NetworkClan-Kiosk-FCSIT-App.git`
2. **Ensure you are on master:** `git checkout master`
3. **Install dependencies:** `flutter pub get`
4. **Run the app:** `flutter run`

##  Team Rules
- Never push directly to `master`.
- Create a new branch for every feature: `git checkout -b feature-yourname-taskname`
- Push your branch and create a **Pull Request** for review.
